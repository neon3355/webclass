# 응용프로그래밍 화면구현 수업 자료

GitHub Pages로 배포하는 형성평가·연습 페이지 모음입니다.

## 폴더 구성

| 폴더 | 내용 | 학생용 주소 |
|---|---|---|
| (맨 위) `index.html` | 수업 자료 목록 첫 화면 | `https://아이디.github.io/저장소이름/` |
| `quiz-basic/` | 화면구현 기초 형성평가 (10문항) | `.../quiz-basic/` |
| `quiz-style-css/` | style.css 형성평가 (20문항) | `.../quiz-style-css/` |
| `style-css-practice/` | style.css 직접 입력 연습 (4단계) | `.../style-css-practice/` |
| `quiz-jsp-pages/` | JSP 페이지 구성 형성평가 (20문항) | `.../quiz-jsp-pages/` |

## 새 자료 추가하는 법

1. 새 폴더를 만들고 그 안에 `index.html`을 넣는다. (폴더 이름은 영어 소문자와 - 만 사용)
2. 맨 위 `index.html`의 목록에 `<a class="item" href="새폴더이름/">` 카드를 하나 복사해서 추가한다.
3. 커밋하면 1~2분 뒤 사이트에 반영된다.

## 자료 고치는 법

해당 폴더의 `index.html`을 새 파일로 덮어쓰기(업로드)하면 된다. 주소는 바뀌지 않는다.
