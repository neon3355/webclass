# 화면구현 연습실

응용프로그래밍 화면구현 수업용 연습 사이트입니다. 학생이 로그인해서 타자 연습 → 코드 연습(실행 화면 미리보기) → 형성평가 순서로 스스로 공부하고, 선생님은 관리자 화면에서 반별로 과제를 배포하고 진행 상황을 봅니다.

주소: https://neon3355.github.io/webclass/
(저장소 Settings → Pages → Deploy from a branch → `main` / `(root)` 로 켜야 열립니다.)

## 폴더 구성

| 위치 | 내용 |
|---|---|
| `index.html` | 입장(학번·이름) + 오늘의 순서 |
| `typing/` | 타자 연습 (낱말 → 기호 → 짧은 코드 → 코드 한 줄) |
| `code/` | 코드 연습 (파일별 보고 쓰기 / 외워 쓰기) |
| `quiz/` | 형성평가 목록과 각 평가 페이지 |
| `report/` | 내 과제 현황 (오늘 · 날짜별 · 전체) |
| `admin/` | 관리자 화면 (반별 과제 배포, 학생 현황) |
| `server/Code.gs` | 구글 시트에 붙여 넣는 서버 코드 |
| `assets/data.js` | **타자 낱말과 수업 코드 원본** — 내용을 바꿀 때는 이 파일만 고칩니다 |
| `assets/config.js` | 사이트 이름, 서버 주소(`apiUrl`) |
| `assets/common.js`, `common.css` | 상단 바(학번·이름 표시), 기록 저장, 공통 디자인 |

## 내용 고치기

- **타자 낱말 추가**: `assets/data.js`의 `WC_TYPING`에서 해당 단계 `items`에 낱말을 추가합니다.
- **수업 코드 바꾸기**: `assets/data.js`의 `WC_STYLE_LINES`(style.css)와 `wcProgram`(JSP 파일 틀). 한 줄이 `{ t: "코드", h: "외워 쓰기에서 보이는 설명", in: 들여쓰기 단계 }` 입니다. `{ auto: "..." }`는 Eclipse가 자동으로 만드는 줄(학생이 쓰지 않음), `{ blank: 1 }`은 빈 줄입니다. `{sid}`, `{name}`은 학생의 학번·이름으로 바뀝니다.
- **형성평가 추가**: `quiz/새폴더/index.html`로 넣고, `</body>` 앞에 아래 두 줄을 넣은 뒤 `quiz/index.html`의 `SECTIONS`에 한 줄 추가합니다.
  ```html
  <script src="../../assets/config.js"></script>
  <script src="../../assets/common.js"></script>
  ```

## 과제(프로그램) 추가하기

`assets/data.js` 맨 아래 `WC_ASSIGNMENTS`에 묶음을 하나 더 씁니다. 프로그램 제목, 소개 글, 입력 화면의 파일 이름·항목만 정하면 style.css · header.jsp · footer.jsp · index.jsp · 입력 화면이 자동으로 만들어집니다.

```javascript
wcProgram({ id: "a3", name: "과제 3", title: "동아리 가입 관리 프로그램", intro: "동아리 가입 정보를 관리하는 프로그램입니다.",
  form: { file: "join", menu: "가입신청", title: "가입신청", submit: "가입등록", rows: [["동아리명", "club_name"], ["학생명", "user_name"]] },
  list: { file: "joinlist", menu: "가입현황" } })
```

`id`는 한 번 정하면 바꾸지 마세요(학생 기록이 이 id로 저장됩니다).

## 서버 설정 (회원가입·로그인·관리자 화면)

학생 명단, 활동 기록, 반별 과제 배포 상태는 선생님 구글 계정의 **구글 시트**에 저장됩니다. 한 번만 설정하면 됩니다.

1. 구글 시트를 새로 만듭니다. (이름 예: `화면구현 연습실`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 처음 보이는 코드를 모두 지우고, 이 저장소의 `server/Code.gs` 내용을 통째로 붙여 넣습니다.
4. 맨 위의 `var ADMIN_PW = "admin1234";`에서 **관리자 비밀번호를 바꿉니다.** (이 비밀번호는 구글에만 있고 GitHub에는 올라가지 않습니다.)
5. 저장한 뒤 오른쪽 위 **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고, 권한 요청이 나오면 허용합니다.
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해서 `assets/config.js`의 `apiUrl: ""` 따옴표 안에 넣고 저장(커밋)합니다.

이제 사이트 첫 화면에 로그인/회원가입이 나타나고, `…/webclass/admin/`에서 관리자 화면을 쓸 수 있습니다.

- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. (URL은 그대로입니다.)
- 시트에는 `students`(명단·비번), `log`(활동 한 번에 한 줄), `assign`(반별 배포) 탭이 자동으로 생깁니다. 비번을 바꿔 주거나 학번을 고칠 때는 `students` 탭에서 직접 고치면 됩니다.
- `apiUrl`을 비워 두면 예전처럼 학번·이름만 넣고 쓰는 방식으로 돌아가고, 모든 과제가 다 보입니다.

## 관리자 화면에서 하는 일

- **반 고르기**: 학번 가운데 두 자리가 반입니다(20101 → 2-1, 20401 → 2-4). 가입한 학생이 있는 반이 목록에 나오고, 미리 배포해 두려면 "반 추가"에 `204`처럼 넣습니다.
- **과제 배포 / 거두기**: 배포한 과제만 그 반 학생의 「코드 연습」에 보입니다. 나중에 배포한 것이 「이번 과제」입니다.
- **수기 과제지**: 학생을 체크하고 「출력하기」를 누르면 학번·이름이 인쇄된 따라 쓰기 과제지가 나옵니다. 출력한 학생은 「수기 과제지 관리」에 기록되고, 받은 뒤 [제출 확인]을 누릅니다. (시트의 `sheets` 탭)
- **학생 현황**: 비번, 마지막 로그인, 오늘 활동 수, 타자 최고, 파일별 보고 쓰기·외워 쓰기 완료 여부. 학생 줄을 누르면 날짜별 기록이 나옵니다.

## 알아둘 점

- 비밀번호는 선생님이 볼 수 있도록 시트에 그대로 저장됩니다. 학생에게 다른 사이트에서 쓰는 비밀번호를 쓰지 않도록 안내하세요(가입 화면에도 적혀 있습니다).
- 서버를 연결하면 어느 컴퓨터에서 로그인해도 같은 기록이 보입니다. 공용 PC에서는 끝날 때 오른쪽 위 **로그아웃**을 누르게 하세요.
- 구글 시트 응답은 1~3초 걸립니다. 한 반이 동시에 가입해도 순서대로 처리됩니다.
